## Steps (Super Simple):

### 1️⃣ Go to Railway
👉 Visit: **https://railway.app**
👉 Click **"Login"** → **"Login with GitHub"**

### 2️⃣ Create Project
👉 Click **"New Project"**
👉 Select **"Deploy from GitHub repo"**
👉 Choose: **`portfolio-3d`**
👉 Click **"Deploy Now"**

### 3️⃣ Add Environment Variables
👉 Click on your service
👉 Go to **"Variables"** tab
👉 Add these 3 variables:

```
NODE_ENV = production
JWT_SECRET = my-secret-key-123
PORT = 3000
```

### 4️⃣ Wait 2-3 Minutes
Railway will:
- ✅ Build Docker image
- ✅ Install dependencies
- ✅ Build admin panel
- ✅ Start server

### 5️⃣ Get Your URL
👉 Click **"Settings"** tab
👉 Find **"Public URL"** (looks like: `your-project.up.railway.app`)
👉 Click it!
